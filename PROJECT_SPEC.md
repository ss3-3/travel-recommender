# Project Specification

## Project Information

Project Title

Travel Destination Recommendation System
using
Content-Based Filtering and Collaborative Filtering
for Personalized Multi-Destination Recommendation

------------------------------------------------

## Objective

Develop and compare

• Content-Based Filtering (CBF)

• Collaborative Filtering (CF)

for personalized multi-destination travel recommendation.

The study focuses on recommendation quality rather than route optimisation.

------------------------------------------------

## Dataset

Dataset:
tourism_recommendation_dataset_en.csv

Characteristics

• ~100,000 user-attraction interactions
• 10,000 users
• 431 attractions

------------------------------------------------

## Project Scope

Included

✓ Data preprocessing

✓ Exploratory Data Analysis

✓ Content-Based Filtering

✓ Collaborative Filtering

✓ Model evaluation

✓ Multi-destination itinerary presentation

✓ Streamlit demonstration

------------------------------------------------

Excluded

✗ Route optimisation

✗ Travelling Salesperson Problem (TSP)

✗ Ant Colony Optimisation (ACO)

✗ Genetic Algorithm (GA)

✗ Deep Learning

✗ Hybrid Recommendation

------------------------------------------------

## Algorithms

Model A

Content-Based Filtering

Possible techniques

• TF-IDF

• Cosine Similarity

------------------------------------------------

Model B

Collaborative Filtering

Possible techniques

• User-Based CF

or

• Item-Based CF

or

• Matrix Factorization (SVD)

(final implementation will depend on experimental results)

------------------------------------------------

## Evaluation Metrics

Primary

• Precision@K

• Recall@K

• F1-score

Secondary

• RMSE

• MAE

Optional

• NDCG@K

------------------------------------------------

## Frontend

Framework

Streamlit

Purpose

Research demonstration only.
